# QR-Reader-on-PC

PC のカメラで QR コードを読み取るブラウザ用ツールです。インストールは要りません。

## できること

- カメラで QR コードを読み取る（複数のカメラを切り替え可能）
- 読み取った内容を自動でクリップボードにコピー（オフにもできます）
- 内容が `http://` / `https://` の URL なら「URLを開く」ボタンを表示（勝手には開きません）
- 画像ファイルのドロップや、Ctrl+V でのスクリーンショット貼り付けからも読み取り可能
- 読み取り履歴（最新 100 件、ブラウザ内にだけ保存）
  - 履歴にチェックを付けて「選択した項目を結合してコピー」を押すと、読み取った順に繋げた文字列をコピー（Shift+クリックで範囲選択）
- 入力した文字列から QR コード画像を作成（日本語対応。PNG で保存、または画像としてコピー）
  - 文字列を貼り付けると、先頭から1文字ずつ読み込みながら QR コードが組み上がっていくアニメーション付き（チェックを外すとオフ。サイズ・誤り訂正レベルの変更時にもアニメーションさせる設定あり）
  - 「長い文字列を分割する」をオンにすると、指定した文字数ごとに区切って複数の QR コードを作成（最大 50 枚）。「次へ」「前へ」ボタンかキーボードの → / ← で1枚ずつ表示

### 長い文字列を分割して受け渡す

1. 送る側：「長い文字列を分割する」をオンにして文字数を指定し、文字列を入力
2. 受け取る側：「次へ」を押しながら 1 枚目から順にカメラで読み取る
3. 受け取る側：履歴で読み取った分にチェックを付け、「選択した項目を結合してコピー」を押す

## 使い方

1. このリポジトリをダウンロードし、`index.html` を Chrome / Edge / Firefox で開く
   （`vendor/` フォルダも一緒に置いてください）
2. 「カメラを起動」を押してカメラの使用を許可
3. QR コードをカメラにかざす

GitHub Pages で公開すれば、URL を開くだけで使えます
（Settings → Pages → Branch: `main` / root）。

## 仕組み

- カメラ映像は `getUserMedia` で取得し、解析はすべてブラウザ内で行います。映像や結果を外部に送ることはありません。
- デコードには、ブラウザが対応していれば `BarcodeDetector` を使い、対応していなければ同梱の [jsQR](https://github.com/cozmo/jsQR)（Apache-2.0, `vendor/`）を使います。
- QR コードの生成には同梱の [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)（MIT, `vendor/`）を使います。
